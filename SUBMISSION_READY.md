## Known Behaviors

### First Run
1. Loads CSV from `/app/fixtures/build_manifest.csv`
2. Creates DuckDB database at `/app/releases.duckdb`
3. Deduplicates and applies withdrawals
4. For each publishable bundle:
   - Creates canonical JSON descriptor
   - Signs with OpenSSL CMS
   - Submits to `http://127.0.0.1:7070/v1/publications`
   - Stores publication record

### Second Run (Idempotent)
1. Loads existing database
2. For each publishable bundle:
   - Finds existing publication record
   - Replays same receipt without re-submitting
3. Output is identical to first run

### Error Scenarios
- Gateway unreachable → Error propagated
- Invalid signature → Status: UNTRUSTED_SIGNATURE
- OpenSSL failure → Error with details
- Database error → Caught in finally block
